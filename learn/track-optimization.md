This track is a reading order for getting more from each session: managing context, choosing models, delegating, cutting prompts and measuring what you change. It reorders articles that also appear in the levels, and the reading time is 95 minutes.

## Who This Track Is For

Take this track if your sessions feel slow, long or repetitive and you want to improve them with evidence. It starts with how context works, because most later advice depends on it. You can read it alongside Levels 1 to 3.

## Reading Order

1. [How Context Works](../kb/optimization/how-context-works.md) (7 min). Everything else in this track depends on knowing what fills the context window.
2. [Clear, Compact and Hand Off](../kb/optimization/clear-compact-and-hand-off.md) (7 min). These are your tools for resetting a session: `/clear`, `/compact`, a handoff note you write and `/rewind`.
3. [Long Sessions and Context Rot](../kb/troubleshooting/long-sessions-and-context-rot.md) (6 min). Learn the symptoms of a bloated session and the fixes in the order to try them.
4. [New Session or Continue](../kb/decision-guides/new-session-or-continue.md) (5 min). A decision table turns the last three articles into a choice you can make quickly.
5. [Model and Effort Trade-offs](../kb/optimization/model-and-effort-trade-offs.md) (8 min). With context under control, tune model and effort by starting low and raising them when the work comes back shallow.
6. [Which Model and Effort](../kb/decision-guides/which-model-and-effort.md) (5 min). A decision table that sums up the previous article.
7. [Delegating to Subagents](../kb/optimization/delegating-to-subagents.md) (8 min). Keep the main thread lean by sending heavy reading to a subagent that returns only its conclusion.
8. [Reading Your Usage, Context and Skills](../kb/optimization/reading-your-usage-context-and-skills.md) (7 min). Read `/usage`, `/context` and `/skill-doctor` so you can see where your budget goes.
9. [Permission Tuning for Fewer Prompts](../kb/workflow/permission-tuning-for-fewer-prompts.md) (8 min). Fewer approval prompts save time, so allow safe commands and weigh Auto mode.
10. [Subagents by Design](../kb/workflow/subagents-by-design.md) (9 min). Design your own subagents with one purpose, a tool allowlist and a defined return format.
11. [Fast Mode: When It Pays](../kb/optimization/fast-mode-when-it-pays.md) (6 min). Decide separately whether a faster configuration is worth its cost. The documentation labels it a research preview.
12. [Profiling and Benchmarking with Claude](../kb/optimization/profiling-and-benchmarking-with-claude.md) (9 min). Measure the speed of code, change one thing and measure again.
13. [Measure a Workflow Before and After](../kb/optimization/measure-a-workflow-before-and-after.md) (10 min). Apply the same discipline to your own workflow, using metrics you can collect.
